# Trip Coordinator Platform

A web app for planning trips. Your itinerary flags conflicts, travel documents are read by AI and confirmed by you, an Explore tab suggests things to do in the free time before your next booking, and an Ask AI chat answers questions about your own trips.

Built with Java and Spring Boot, React, PostgreSQL and AWS.
